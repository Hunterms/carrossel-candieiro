# carrossel-candieiro

Bancada do carrossel do Terreiro do Candieiro, servida pelo GitHub Pages.

`index.html` e a peca `_uma-tela` construida em
`candieiro-conteudo/carrossel/dist/`: autossuficiente, com fonte e foto
embutidas, barra de edicao no navegador e exportacao de PNG 1080x1350.

Para atualizar: rode `./build.sh _uma-tela` no projeto de conteudo e copie o
`dist/_uma-tela.html` por cima do `index.html` daqui.

`.nojekyll` existe porque o Jekyll ignora arquivo que comeca com `_`.
